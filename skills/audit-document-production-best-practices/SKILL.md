# Audit Document Production Best Practices

Document production for an FMCSA audit is high-stakes. Disorganized response signals carrier deficiency.

## Initial response steps
- Acknowledge the request
- Confirm scope (which documents, which time period)
- Set internal deadline (a week before FMCSA deadline)
- Designate single responder

## Document organization
- One folder per topic area (DQ, HOS, Vehicle, D&A, etc.)
- Within each folder: subfolders per driver/vehicle/date
- Consistent file naming: [Date]-[Type]-[Driver/Vehicle].pdf
- All in PDF (or as required by FMCSA)
- Index file at top explaining the contents

## What to include
- Only what was requested (no more)
- Complete (no missing pages)
- Legible (no shadows, no skewed scans)
- Current (most-recent versions)

## What to exclude
- Personal information beyond what's required
- Internal discussions about the audit (privileged)
- Documents from outside the audit period
- Documents on a separate matter

## Transmission methods
- FMCSA Audit Portal (preferred)
- Email (with limits on attachment size)
- Mail (for very large submissions)
- Drop off (if local)

## Common errors
- Missing pages in scanned documents
- Outdated documents submitted (e.g., expired medical card)
- Inconsistent date formats (some MM/DD, others DD/MM)
- File names indecipherable
- No index, just dumped documents

## After submission
- Confirm receipt
- Note FMCSA's response (questions, follow-up requests)
- Track to closure
