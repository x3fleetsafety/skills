# SMS Methodology Changes — Recent Updates

FMCSA periodically revises the Safety Measurement System methodology. Understanding the current state and pending changes helps carriers respond strategically.

## Current methodology (effective 2020 onwards)
- Time-weighted violations (recent counts more than older)
- 24-month rolling window
- Peer group reassignment quarterly
- Crash Indicator includes preventability-determined crashes

## Recent updates and proposals
- **CSA Compliance Safety Accountability program review** — FMCSA periodically requests comment on methodology
- **Item Response Theory (IRT)** — proposed for inspection severity weighting (replacing current schema)
- **Crash Preventability Determination program** — formalized; allows challenge of crash-counting
- **State conviction reporting standardization** — multi-state effort to ensure consistent reporting

## What carriers should monitor
- Federal Register notices on SMS changes
- FMCSA Public Listening Sessions and rule-making
- Bookmark fmcsa.dot.gov/SafetyManagement methodology page

## How methodology changes affect carriers
- BASIC scores recalculate at each methodology change
- Carriers may see sudden score shifts even without behavior change
- Peer group reassignments may move carriers in/out of alert
- New methodology becomes effective on FMCSA's published date (typically 30-60 day notice)

## Recent industry concerns
- IRT proposal: severity-weight changes may benefit smaller carriers (less inspection volume)
- Crash preventability: more discretion for carriers to challenge
- "Safety Fitness Determination" replacing current rating system — open question
