# Credit Report for Driver Hiring

Credit reports for driver hiring are uncommon and potentially discriminatory. Use carefully.

## Federal law
- FCRA applies to credit reports used in employment
- Credit report definition includes credit-related background checks
- FCRA disclosure + adverse action requirements apply

## EEOC concerns
- Credit checks may disparately impact protected classes
- Title VII Title VII prohibits discrimination based on race, sex, national origin
- Bad credit history correlates with these classes (statistically)
- EEOC has investigated employers using credit checks; some enforcement actions resulted

## When credit check is permissible
- Job involves cash handling (drivers hauling valuables)
- Job involves financial responsibility (cargo with high value)
- Job-relatedness can be demonstrated
- Particularized inquiry per applicant (not blanket policy)

## When credit check is NOT recommended
- General-freight driver
- Driver hauling routine cargo
- Hourly wage drivers
- Drivers with otherwise clean records

## Practical workflow if used
1. Inform applicant via FCRA disclosure (separate document)
2. Get written consent
3. Order credit report
4. If derogatory marks found:
   - Send pre-adverse action notice
   - Allow 5 business days for applicant to respond
   - If still moving toward adverse action, send final notice
5. Document the decision

## State law
- Some states restrict use of credit reports in employment
- California (AB-1228) restricts use to certain jobs
- Connecticut, Maryland, Vermont have laws
- Always check state law before using

## Common carrier practice
- Most general-freight carriers do NOT run credit checks
- High-value cargo carriers (jewelry, art, electronics) may run them
- Cash-handling carriers (cash transport) typically run them
- Bonding requirements may require them (in commercial bond context)
