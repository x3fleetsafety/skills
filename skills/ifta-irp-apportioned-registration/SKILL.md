# IRP Apportioned Registration

IRP is the registration system that allows commercial vehicles to operate in multiple states with one license plate. Different from IFTA (which is fuel tax).

## What IRP is
- Vehicle registration for interstate operations
- One license plate that's recognized in all IRP member jurisdictions (US states + Canadian provinces)
- Apportioned fees based on miles in each state
- Required for any commercial vehicle that crosses state lines AND operates in 2+ jurisdictions

## What IRP is NOT
- Not your operating authority (FMCSA MC# is separate)
- Not your USDOT number (that's separate)
- Not IFTA (that's fuel tax)
- Not state DMV registration (that's the underlying registration, IRP is the apportioned overlay)

## Initial registration
- Apply through base state (where vehicle is "based")
- Submit fleet roster, expected mileage, registration fees
- Receive apportioned plates within 30-60 days
- Renewal annually

## Quarterly mileage reporting
- IRP requires quarterly distance reports
- Distance by state for each vehicle
- Submitted via base state portal
- Used to calculate apportioned fees

## Fees and apportionment
- Fees calculated by mileage in each state
- Example: 30% miles in TX, 25% in OK, 20% in AR = fees apportioned accordingly
- Each state has its own fee rate per mile

## Common errors
- Vehicle plates wrong state (must be base state)
- Mileage reporting late or missing
- Apportionment claims (claiming miles in a state where you didn't operate)
- New vehicle not added to IRP fleet immediately

## When to add a vehicle
- Within 30 days of acquisition
- Updates the apportionment percentages
- Required for any vehicle operating interstate

## When to remove
- When vehicle is sold or retired
- Within 30 days
- Update fleet roster
