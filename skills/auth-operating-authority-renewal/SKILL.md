# Operating Authority Renewal

Operating authority does NOT have a fixed renewal cycle — but specific requirements must be maintained continuously. Failure = revocation.

## What must be maintained
- Insurance (BMC-91 + BMC-91X if applicable)
- Process agents (BOC-3 designations current)
- Address + contact information current
- Officer information current
- Operating in accordance with authority scope

## What triggers renewal action
- Insurance lapse → 30-day grace period to reinstate
- Process agent missing → notice + reinstatement window
- Address change not reported → eventual deactivation
- Long-term operational hiatus → possible deactivation

## Insurance renewal
- BMC-91 must be on file at all times
- Insurance carrier notifies FMCSA when policy changes
- Carrier must verify renewal before policy lapses

## Process agent renewal
- BOC-3 must be on file in every state of operation
- Process agent agreement must remain current
- If a state agent's information changes, BOC-3 must be updated

## Fees (current)
- No annual renewal fee for operating authority itself
- Insurance premium (varies by carrier)
- Process agent fees (per state, ~$50-150 typically)
- Application fees only on initial setup

## Reinstatement after lapse
- File request for reinstatement
- Pay reinstatement fee
- Provide proof of insurance + process agents
- Wait for FMCSA approval (varies; typically 60-90 days)
- May require resolving underlying issue (e.g., past violations)

## Common errors
- Insurance lapses without notice
- Process agents allowed to expire
- Address updates not filed
- Officer changes not reported (delays applications)
