# Trailer Types and Specifications

Trailer choice defines the freight a carrier can haul. Most fleets standardize on one or two trailer types based on commodity focus, but understanding the broader market unlocks lane diversification.

## Major trailer types

### Dry van (53' standard)

| Spec | Standard |
|---|---|
| Length | 53' (most), 48' (older / specific lanes) |
| Width | 102" |
| Inside height | 110"–112" |
| Capacity | ~26 standard pallets (52 if double-stacked) |
| Empty weight | 13,500–15,000 lb |
| Payload (legal) | ~45,000 lb |
| Door types | Swing (most), roll-up (LTL) |

Dry van is ~60% of U.S. truckload market. Highest competition, most freight available, simplest operation.

### Refrigerated ("reefer", 53')

| Spec | Standard |
|---|---|
| Length | 53' |
| Width | 102" |
| Inside height | 100"–106" (insulation cuts ~6") |
| Capacity | ~24 standard pallets |
| Empty weight | 17,000–18,500 lb |
| Payload (legal) | ~42,500 lb |
| Reefer unit | Carrier Transicold or Thermo King |
| Temp range | -20°F to +90°F |

Reefer pays $0.30–$0.60 more per mile than dry van. Operating cost higher (reefer fuel, maintenance, washouts). Major lanes: California produce, Florida produce, Midwest meat / processed food.

### Reefer unit choice

| Vendor | Strengths | Service network |
|---|---|---|
| Carrier Transicold | Slightly lower fuel burn, strong parts network | National |
| Thermo King (TK) | Robust in long-haul, integrated telematics | National |

Both vendors offer ~3,000-hour service intervals, $25K–$40K unit cost, 7–10 year life expectancy.

### Flatbed (48' or 53')

| Spec | Standard |
|---|---|
| Length | 48' (most common) or 53' |
| Width | 102" |
| Deck height | 60" |
| Empty weight | 11,000–12,000 lb |
| Payload | ~48,000 lb |

Used for steel, lumber, building materials, machinery. Driver loads/unloads via straps, chains, tarps. Higher driver skill required. Pay typically $0.10–$0.30 over dry van.

### Step-deck (53')

| Spec | Standard |
|---|---|
| Lower-deck length | 37'–40' |
| Upper-deck length | 10'–13' |
| Lower deck height | 38"–42" |
| Use case | Tall freight needing < 13'6" overall height |

For loads where the cargo + flat deck height would exceed 13'6" legal height.

### Conestoga / curtainside

Flatbed or step-deck with retractable canvas/aluminum cover. Combines flatbed loading flexibility with weather protection. Used for cured cargo (steel, machinery) that benefits from rain/sun protection. Premium $0.05–$0.15/mile.

### Tanker (food-grade, fuel, chemical)

| Type | Capacity | Notes |
|---|---|---|
| DOT 406 (gasoline / petroleum) | 8,800 gal | Most common fuel tanker |
| DOT 407 (chemical) | 6,500 gal | Stainless or aluminum |
| DOT 412 (corrosive) | 6,000 gal | Lined / specialized |
| Food-grade (dairy, juice) | 6,500 gal | Stainless, washout requirements |
| Pneumatic dry-bulk | 1,000–1,800 cu ft | Cement, plastic pellet |

Tanker requires Tank endorsement (N) and often HAZMAT (H). Pay $0.20–$0.50 over dry van.

### Dump trailer

End-dump, side-dump, or belly-dump. For aggregate, asphalt, scrap. Local/regional. Tight regs in some states.

### Lowboy / heavy haul

| Type | Use |
|---|---|
| RGN (removable gooseneck) | Construction equipment, oversized loads |
| Detachable | Heavy steel, transformers |
| Multi-axle | Permitted heavy haul up to 200,000+ lb |

Requires oversized/overweight permits per state. Pay $1.50–$5.00+ per mile depending on configuration.

### Auto hauler

7–10 vehicle capacity. Bilateral 53' or stinger steer. Driver must be skilled at loading. Major OEM contracts (Ford, GM, Stellantis) drive volume.

### Intermodal chassis

20', 40', 45', 48', 53' chassis for shipping containers. Owned by IEPs (chassis pools) or carriers. Drayage-specific.

## Length and weight rules

| Rule | Federal limit | Notes |
|---|---|---|
| Gross vehicle weight (GVW) | 80,000 lb on interstate | State permits raise to 90K–120K |
| Tandem axle weight | 34,000 lb | Sliding tandem to balance |
| Steer axle weight | 12,000 lb | Most states |
| Trailer length | 53' (NHS interstates and reasonable access) | 48' restricted lanes still exist |
| Overall height | 13'6" | Eastern states stricter; routes pre-checked |
| Overall width | 102" | 96" in a few old jurisdictions |
| Overall length (tractor + trailer) | No federal max | Most states 65'–75' |

## Tractor-trailer matching

Tractor wheelbase + 5th wheel position + trailer kingpin setting must compatible. Long-wheelbase tractor with forward kingpin won't turn in tight docks. Critical for:
- Sleeper-cab tractors with 53' trailers: standard kingpin 36"–46"
- Day-cab with 28' pups: kingpin 24" (California configuration)

## Liftgate options

| Type | Capacity | Cost |
|---|---|---|
| Tuck-under / rail-mounted | 2,000–4,000 lb | $5,000–$8,000 |
| Cantilever | 3,500–5,500 lb | $7,000–$10,000 |
| Rail-gate (heavy duty) | 5,500+ lb | $10,000+ |

Adds 1,000–1,800 lb to trailer empty weight. Worth it for LTL or any "no-dock" delivery. Boosts rate $0.10/mi+ on routes needing it.

## Common mistakes

- Buying 53' reefer for short-lane LTL → wrong tool, can't fit at customer dock
- Going cheap on reefer unit → unit failure on a load of $50K produce = total loss
- Skipping liftgate spec → losing access to half the delivery market
- Skip-tray flatbed for tall freight → needs step-deck
- Tankers without proper endorsement / washouts → contamination claim is career-ending
- Mismatched kingpin → can't pull standard trailers on a vocational tractor
- Buying spec for current lane only → can't repurpose when lane disappears
