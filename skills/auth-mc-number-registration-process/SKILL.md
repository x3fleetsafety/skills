# MC Number Registration Process

An MC number is required for motor carriers transporting regulated property or passengers in interstate commerce. Different from DOT number.

## Who needs MC number
- For-hire interstate motor carriers
- For-hire interstate passenger carriers
- Brokers/freight forwarders (also Property/Household Goods)

## Who does NOT need MC number
- Intrastate carriers (state authority only)
- Private (not-for-hire) carriers (DOT number sufficient)
- Some specialized exemptions (agricultural, etc.)

## Application steps
1. Obtain a DOT number (free, instant via FMCSA)
2. Submit OP-1 application (or OP-2 for broker)
3. Pay $300 application fee
4. Establish insurance (BMC-91 + BMC-91X if applicable)
5. Designate process agents in each state of operation (BOC-3)
6. Wait for review (30-60 days typical)
7. MC number issued

## Required documents
- Form OP-1 (or OP-2)
- Form BOC-3 (process agents)
- Form BMC-91 (insurance proof)
- Form BMC-32 (cargo insurance, if applicable)
- USDOT registration (already required)
- Process agent agreements (per state)

## Common issues
- Application errors → return to applicant
- Insurance not filed correctly → delay
- Process agents not designated → delay
- Fees not paid → delay

## Maintenance
- Annual update of MCS-150 (carrier info update)
- Insurance must remain current
- Process agent agreements maintained
- Annual fees (if any) paid

## Renewal vs maintenance
- MC numbers don't expire if maintained
- Failure to maintain → revocation
- Reinstatement possible (but costs + time)
