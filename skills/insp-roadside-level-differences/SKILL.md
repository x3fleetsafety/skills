# Roadside Inspection Levels — I, II, III, IV, V, VI Explained

The Commercial Vehicle Safety Alliance (CVSA) defines 6 inspection levels. Each has different scope and time investment.

## Level I — North American Standard
- Most comprehensive (45-60 min)
- Driver + vehicle complete inspection
- Driver: license, medical card, RODS, DQF, drug/alcohol
- Vehicle: brakes, suspension, tires, lights, frame, exhaust, fuel, cargo securement, more
- Yields the CVSA decal if clean

## Level II — Walk-around (Driver + Vehicle)
- Driver inspection same as Level I
- Vehicle inspection without crawling under (no brake adjustment check)
- 20-30 minutes
- Most common for "follow-on" inspections

## Level III — Driver only
- Driver license, medical, RODS, drugs/alcohol
- Vehicle quick visual check only
- 10-15 minutes
- Frequent at state border crossings

## Level IV — Special studies
- Targeted: brake performance, specific vehicle type
- One-time special operations
- Same vehicle + driver elements as Level II usually

## Level V — Vehicle only
- No driver present (or driver in lodging, fueling)
- Vehicle complete inspection
- 30-45 minutes

## Level VI — Radioactive shipment
- Hazmat-specific
- More thorough than Level I for the hazmat aspects
- Required for highway route-controlled radioactive shipments

## What inspectors look for at each
- All levels: license validity, current medical, current vehicle docs
- Level I/II/V: detailed vehicle violations
- Level III/IV: driver-focused violations
- Level VI: hazmat security + handling

## Pitfall
Driver mistakes Level III (driver-only) for a Level I and is surprised when an inspector doesn't crawl under. Different levels = different scope. Train drivers on what each looks like.
