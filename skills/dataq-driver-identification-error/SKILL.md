# DataQ Filing for Driver Identification Errors

Driver identification errors are one of the highest-success DataQ challenge categories. If the inspection report names the wrong driver, you have grounds for reversal.

## When this applies
- Inspector wrote down wrong driver name
- Inspector recorded wrong driver license number
- Inspection report shows a name that doesn't match your driver records
- Two drivers were swapped on the same vehicle
- Driver was hired by another carrier at the time of inspection

## Evidence needed
- Original inspection report
- Driver's actual location and activity at time of inspection (dispatch records, ELD, fuel receipts)
- Driver employment records showing this driver was NOT operating the vehicle at the cited time
- If applicable, vehicle GPS data confirming who was driving

## Filing steps
1. Go to fmcsa.dot.gov/DataQ
2. Search for the specific inspection ID
3. Open "Inspection Report" challenge
4. Category: "Driver Information"
5. Subcategory: "Wrong driver named"
6. Provide narrative + upload evidence
7. State agency receives, reviews, decides
8. Decision typically within 30-60 days

## Success rate
- Documented officer error (wrong name written down): ~95%
- Driver was actually operating: 0% (the inspection stands)

## What if you can't prove who was actually driving?
You may still file showing the named driver was NOT operating. State will close as "Insufficient evidence" — but you may still have a chance for reduction if multiple inconsistencies exist.
