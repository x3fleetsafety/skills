# DOT Number + MCS-150 Update Requirements

Per § 390.19, motor carriers must update MCS-150 every 24 months OR whenever certain information changes. Failure can result in revocation.

## Required update triggers (any of these)
- Every 24 months (biennial update)
- Carrier name change
- Address change
- Number of power units changes
- Number of drivers changes
- Type of operation changes
- Operating authority changes
- Owner/officer changes
- Hazmat carrier changes

## When to update
- **Biennial**: 24-month anniversary of last update
- **Immediate**: any of the trigger events

## What's updated
- Carrier identification
- Operations data
- Vehicle counts
- Driver counts
- Hazmat status
- Insurance status
- Officer information

## How to update
- USDOT/MC Online (preferred): fmcsa.dot.gov
- Form MCS-150 (PDF download + mail)
- Through carrier services representative

## Consequences of failure
- Initial: warning letter
- Continued: registration deactivation
- Severe: revocation of operating authority
- Restart: must apply for reinstatement

## Common errors
- Update missed by 1-3 months
- Update made but data incorrect
- Multiple operations not consolidated
- Officer changes not reported

## Carrier oversight
- Compass tracks MCS-150 update dates
- Reminder 90 days before 24-month deadline
- Alert when triggering event occurs
- Audit-quality documentation

## CFR citations
- **49 CFR § 390.19**
