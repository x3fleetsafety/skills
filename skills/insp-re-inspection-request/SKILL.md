# Re-Inspection Request

A re-inspection request is rare but possible. Useful when initial inspection was botched or new evidence emerged.

## When to request
- Inspector wrote violations that don't apply
- Inspector used wrong procedures (e.g., wrong test for brakes)
- Driver was prevented from showing evidence
- Multiple inspectors at the site disagree
- Vehicle was inspected for a violation it doesn't have

## How to request
1. Document the issue carefully (note inspector ID, time, location)
2. Contact the State DOT or Department of Motor Carrier Safety
3. Submit written request with explanation
4. State decides whether to re-inspect

## State response options
- Re-inspect (full new inspection)
- Re-inspect specific items
- Refuse re-inspection (file a DataQ instead)
- Convert to investigation (rare; happens when issue is officer misconduct)

## What states typically honor
- Documented procedural error
- New evidence not available at original inspection
- Officer's own admission of error
- Multiple-inspector consensus that original was wrong

## What states typically deny
- "We disagree with the violation"
- "The driver was harsh"
- Time has passed (re-inspection within 90 days)

## Risk
A re-inspection might find MORE violations. Some carriers prefer the DataQ route to keep the issue in writing.
